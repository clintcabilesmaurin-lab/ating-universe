# Static Assets Directory

You can place your photos and music files in this folder structure:

- `/public/photos/` - for your photos (e.g. `pangilatan-1.jpg`, `pangilatan-2.jpg`, etc.)
- `/public/music/` - for your audio/song files (e.g. `say-you-wont-let-go.mp3`, `supermarket-flowers.mp3`, `those-eyes.mp3`)
